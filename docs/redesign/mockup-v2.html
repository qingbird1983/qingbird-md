Getting Started with Qingbird

青鸟上手指南 — 一份为跨语言写作者准备的文档

Qingbird is a desktop Markdown translator built for writers who work across languages. It keeps your .md files exactly as they are — only the reading layer changes.

青鸟是一款桌面端 Markdown 翻译工具，为跨语言写作的作者而生。它不改动你的 .md 源文件——改变的只有阅读层。

01Streaming Translation

Translations stream in token by token, so you see the first words almost seamlessly as they arrive:

译文以逐 token 流式输出，几乎在返回的瞬间，第一行文字便无缝地浮现在纸上：

const result = await translate(doc, {
  mode: "bilingual",
  provider: "deepseek",
}); // 流式优先，TTFT 即体验
Cached segments are keyed by content hash, so re-translating an edited doc only costs the diff.
缓存按内容哈希分段建键，改后重译，只需付出增量的代价。

See translation modes for the full matrix.

完整的模式矩阵见「翻译模式」一文。
