## A. 中英对照模式（bilingual）— Task 25 起草

前置：设置中已配置可用翻译源；打开一份含以下要素的 md 文档：
英文标题、英文段落、表格（含英文表头/单元格）、fenced 代码块、
引用块、任务列表、纯中文段落。

- [ ] **A1 对照渲染**：切到「翻译 → 中英对照」。进度走完后，每段英文
  标题/段落/表头/单元格下方（或右侧单元格内）出现浅蓝圆角 tr-box 译文；
  纯中文块**无** tr-box；fenced 代码块内**无** tr-box。
- [ ] **A2 表格内间距**：含译文的单元格高度仅比原文多一个盒子高度，
  单元格底部无多余空白（T25 修复：cells 内 tr-box 无下边距）。
- [ ] **A3 列表内间距**：列表项间距均匀，翻译项与未翻译项节奏一致
  （T25 修复：li 末位 tr-box 下边距清零）。
- [ ] **A4 暗色模式**：系统切深色后 tr-box 换用深色配色（深蓝底、浅蓝字），
  与原文对比度可读。
- [ ] **A5 跑批中切模式**：bilingual 批次进行中切「原文」→ 预览立即回原文、
  无残留 tr-box；迟到 done 不闪现对照内容；再切回对照 → 自动补跑并恢复。
- [ ] **A6 跑批中切形态**：bilingual 进行中切「译文」→ 旧对照 html 不串场
  （回退原文渲染），新批次完成后整页替换为译文形态。
- [ ] **A7 中途停止**：bilingual 批次进行中点停止 → 进度消失、状态回 idle、
  预览不出现半截/错位 tr-box。
- [ ] **A8 重新翻译**：对照模式下「重新翻译」→ 正常重跑（缓存命中近乎瞬时），
  完成后 tr-box 内容刷新。
- [ ] **A9 跑批中编辑**：批次进行中编辑文档 → done 落库被内容护栏拦下，
  预览回退原文渲染，不出现与当前内容错位的旧 tr-box。
- [ ] **A10 滚动跟随**：长文档对照模式下滚动预览，tr-box 随文档流正常滚动，
  无 fixed 漂浮/错位（Overlay 已降级为文档流内盒子，确认无残余浮层实现）。

## D. 进度与停止

- [ ] **D1 进度推进**：翻译批次进行中进度条 done/total 与百分比单调推进，无回跳乱序（gen 防乱序）。
- [ ] **D2 停止即时性**：点「停止」后进度消失、状态回 idle，UI 不残留 running 态。
- [ ] **D3 迟到事件**：停止/切模式后到达的 done 事件不把旧 html 写进预览（stale 护栏）。
